# SkillSwap – A Local Skill Exchange Platform

## Purpose
SkillSwap is an interactive web application designed to help individuals **offer, learn, and exchange skills** within their local community. Whether it's guitar lessons, coding help, yoga classes, or language exchange, users can browse listings, connect with local providers, and book learning sessions easily.  

The platform empowers community-level engagement through skill sharing, enabling users to both teach and learn in a supportive environment.

## Live URL
🔗 [Visit SkillSwap Live](https://skill-swap-a09.pages.dev/)

## Key Features
- **User Authentication (Firebase):** Secure signup, login, and Google social login.
- **Protected Routes:** Only authenticated users can access certain pages like skill details.
- **Responsive Design:** Optimized layout for mobile, tablet, and desktop.
- **Skill Listings:** Skill data dynamically loaded from JSON format.
- **Skill Detail View:** Displays provider details, price, slots available, and description.
- **My Profile Page:** Shows user name, email, photo, and provides update functionality.
- **Forget Password:** Fully functional reset password system.
- **Interactive Animations:** Added using AOS, Swiper.js, and React Hot Toast.
- **Modern Look:** UI built with Tailwind CSS and DaisyUI.
- **Error-Free SPA:** Seamless navigation even on route reloads.

## NPM Packages Used
- `React` – Core
- `aos` – for scroll animations  
- `swiper` – for hero sliders and carousels  
- `react-hot-toast` – for elegant toast notifications  
- `firebase` – for authentication and hosting  
- `react-router-dom` – for client-side routing  
- `tailwindcss` and `daisyui` – for simplified responsive styling  

## Additional Notes
- Firebase configuration keys are secured with **environment variables**.  
- The design is **clean, minimalist, and community-focused** to improve usability and engagement.  
- Hosted on **Netlify**, ensuring smooth deployment and fast loading times.
